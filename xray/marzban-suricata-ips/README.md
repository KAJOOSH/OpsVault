# محافظ ترافیک نود مرزبان

این ابزار ارتباط‌های مشکوک به بدافزار را روی نود مرزبان بررسی و مسدود می‌کند. برای **Ubuntu 22.04 و بالاتر** است. نیازی به واردکردن IP، حتی برای IP شناور، نیست.

## ۱. نصب

با SSH وارد **سرور نود مرزبان** شوید و دستور زیر را اجرا کنید. نود مرزبان باید از قبل روشن و در Docker با شبکهٔ `host` اجرا شده باشد.

```bash
curl -fsSL "https://raw.githubusercontent.com/KAJOOSH/OpsVault/refs/heads/main/xray/marzban-suricata-ips/install-online.sh" -o /tmp/install-marzban-ips.sh \
  && sudo bash /tmp/install-marzban-ips.sh
```

منتظر پیام پایان نصب بمانید. سپس وضعیت را ببینید:

```bash
sudo marzban-ips status
```

## ۲. نمایش زنده

```bash
sudo marzban-ips live
```

این صفحه سرعت ورودی و خروجی، وضعیت بررسی ترافیک، مصرف CPU و RAM و هشدارهای اخیر را نشان می‌دهد. با `Ctrl+C` از صفحه خارج شوید؛ محافظ روشن می‌ماند.

| پیام | معنی و اقدام |
|---|---|
| `RUNNING` | موتور فعال است و ترافیک پردازش کرده است. |
| `IDLE` | موتور فعال است؛ هنوز ترافیکی برای بررسی دیده نشده است. |
| `WAITING` | هنوز اطلاعات تازه‌ای از موتور نرسیده است؛ کمی صبر کنید. |
| `ALERT` | هشدار تازه ثبت شده است؛ رخدادهای پایین صفحه را ببینید. |
| `WARNING` | مسیر بررسی یا صف ترافیک نیاز به رسیدگی دارد. |
| `OFF` | محافظ خاموش است؛ برای روشن‌کردن، دستور `enable` را اجرا کنید. |

نمایش `RUNNING` و نبود هشدار، تضمین نمی‌کند همهٔ ارتباط‌ها سالم‌اند. ترافیک رمز‌شدهٔ ورودی VPN نیز به‌تنهایی قابل تشخیص بدافزار نیست.

## ۳. به‌روزرسانی

برای دریافت و نصب نسخهٔ جدید **خود برنامه** از GitHub:

```bash
sudo marzban-ips upgrade
```

نسخهٔ فعلی و نسخهٔ جدید نمایش داده می‌شوند. برنامه از فایل‌های قبلی نسخهٔ پشتیبان می‌گیرد و حالت خاموش یا روشن را حفظ می‌کند.

برای دیدن نسخهٔ نصب‌شده:

```bash
sudo marzban-ips version
```

قوانین شناسایی هر روز خودکار به‌روز می‌شوند. برای دریافت زودتر آن‌ها:

```bash
sudo marzban-ips update
```

## ۴. خاموش و روشن‌کردن

اگر بعد از نصب افت سرعت یا اختلال داشتید، محافظ را خاموش کنید:

```bash
sudo marzban-ips disable
```

برای روشن‌کردن دوباره:

```bash
sudo marzban-ips enable
```

حالت خاموش بعد از راه‌اندازی مجدد سرور نیز حفظ می‌شود.

## ۵. دیدن رخدادها یا حذف

برای دیدن ارتباط‌های مسدودشده:

```bash
sudo marzban-ips alerts
```

برای حذف برنامه:

```bash
sudo marzban-ips uninstall
```

این ابزار ارتباط مشکوک را محدود می‌کند؛ بدافزار را از دستگاه کاربر پاک نمی‌کند.
